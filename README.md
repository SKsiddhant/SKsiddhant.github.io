# SKsiddhant.github.io

GitHub Pages user site for [@SKsiddhant](https://github.com/SKsiddhant).

This repository does not contain the portfolio itself. Its `index.html` only redirects
visitors to the portfolio, which lives in the
[`portfolio`](https://github.com/SKsiddhant/portfolio) repository and is served at
<https://sksiddhant.github.io/portfolio/>.

The `.nojekyll` file disables Jekyll processing so the static page is served as-is.
